# Prospect Book — full review, 18 September 2026

Scope: all 18 pushed branches, the live Supabase project, the deployed edge functions,
and the repo's own reconciler. Chat transcripts are not readable; every finding below
comes from committed code, the database, or a test that was actually run.

## The one-line answer

Nothing is lost, but **`main` is the stale branch, not the source of truth.** The live
system is running code and a rubric that exist only on unmerged branches. Seven branches
carry real work; three of them integrate cleanly today, four collide over documentation.

## 1. Production depends on an unmerged branch  (most urgent)

`pb-score` v14 is deployed as a one-line entrypoint pinned to a raw GitHub URL:

    .../prospect-grading/d14223c44eb2c92543bddd27fcfc99075fdf890f/supabase/functions/pb-score/index.ts

Commit `d14223c` is reachable **only** from `claude/keen-dirac-q146ng` and its two
descendants. It is not on `main`. If those branches are deleted, GitHub can garbage-collect
the commit and nightly scoring (06:15 UTC) starts failing with a 404 — the function fetches
its own source at runtime.

**Do not delete `keen-dirac-q146ng`, `adoring-hypatia-artdoz` or `wizardly-faraday-ncd1za`
until their work is merged to `main`.**

### The numbering collision

Four chats each wrote a section numbered **§50**:

| Branch | Its §50 |
|---|---|
| `main` | The agency's own website becomes a channel |
| `dazzling-planck` | Sourcing the LinkedIn company page |
| `dreamy-franklin` | The names check reported clean on two names it could not see |
| `vigilant-clarke` | Taking an agency off the board |

`cool-feynman` is the hard case: it renumbers the entire file (§43→49, §44→50 … §49→55) *and*
changes the heading style from `## §N — Title` to `## N · Title`. It cannot be merged
mechanically with any branch that appends a section under the old scheme — which is all of them,
including `main`. Its DECISIONS conflict shows as a single hunk precisely because git sees the
whole file replaced; "resolving" it means choosing one file and discarding the other's content.

**Recommendation: do not merge `cool-feynman`'s renumbering.** Take its rule-2 fix and its
citation corrections, and redo the renumbering last, once everything else has landed — or drop
it. Renumbering a ledger that four other branches are appending to costs more than it returns.

a runner, a source gate, an undo path. But the queue has not moved, and there are two
